Cómo publicar los cambios en el sitio

  1. Importá el propiedades.json que está hoy en el sitio (carpeta data/), así trabajás sobre lo último.
  2. Cargá o editá las propiedades. Las fotos se convierten solas al formato correcto.
  3. Tocá "Descargar todo": te baja un ZIP con el propiedades.json nuevo y las carpetas de fotos listas.
  4. Subí el contenido del ZIP al repositorio: el JSON reemplaza a data/propiedades.json y las carpetas de fotos van adentro de media/. Al subir, el sitio se actualiza solo.

Ojo: las fotos nuevas viven en esta pestaña hasta que descargues el ZIP. Si cerrás antes, las tenés que volver a arrastrar (los datos de texto se guardan solos en este navegador).

La pestaña Consultas es tu registro de leads: cuando llega un WhatsApp, pegá el mensaje y el panel detecta la propiedad y la fuente (cartel, web, Instagram…). Las consultas se guardan en este navegador; bajá el respaldo JSON cada tanto y el CSV cuando quieras verlo en Excel.
